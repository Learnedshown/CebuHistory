# 📜 Sugbo: Chronicles of Cebu

A historical archive website dedicated to preserving and sharing the rich history of Cebu, Philippines. Built with ASP.NET Core MVC (.NET 10), this platform allows users to explore historical stories, view vintage photographs, access primary documents, and contribute their own historical narratives.

---

## 🌟 Features

### 👥 Public Features
- **Browse Historical Stories** - Read articles about Cebu's rich history organized by era and category
- **Search & Filter** - Find stories by era, category, or keywords
- **Photo Gallery** - View historical photographs with metadata (year, location, source)
- **Document Archive** - Access primary sources, maps, decrees, and chronicles
- **Interactive Timeline** - Explore key events chronologically

### 👤 User Features
- **Register / Login** - Create an account to submit stories
- **Submit Stories** - Share your own historical narratives, family memories, or local legends
- **Upload Images** - Upload photos from your computer or use image URLs
- **My Stories Dashboard** - Track all your submitted stories
- **Edit Pending Stories** - Update stories that are waiting for approval or were rejected
- **View Published Stories** - See your approved stories live on the website

### 👑 Admin Features
- **Admin Dashboard** - View analytics (total stories, photos, documents, users)
- **Manage Stories** - Create, edit, delete, and publish stories
- **Approve/Reject User Submissions** - Review user-submitted stories with rejection reasons
- **Manage Photos** - Upload and organize historical photographs
- **Manage Documents** - Upload and categorize historical documents
- **User Management** - Promote users to admin, enable/disable accounts
